# Finance icon
`finance-icon.svg` is the icon on a transparent-backed plate.
`finance-icon-full-bleed.svg` is the opaque icon for iOS and maskable Android; `finance-mark.svg` is the standalone mark.
Re-render with `CHROME=chromium design/finance-icon/render-icon.sh design/finance-icon` (or set `CHROME` to your Chrome binary).
The PNGs in this directory are rendered output, not editable sources.
